# Github API Profile Search

A Django web app used to search Github accounts and their public repos using Github's API.

## Status

Early-stage with no intent of deployment. Core features work.

## What It Does

Lets users search Github profiles and see their public repos.

## Features

- Search bar for looking up Github usernames
- Displays profile info (name, bio, public repo count)
- Lists public repositories with stars, language, an links
- Error handling for invalid usernames and network failures

## Planned Features

- None currently - this project is considered complete for its current scope. 

## Tech Stack

- **Backend:** Python, Django, Requests (for API calls)
- **Frontend:** HTML, CSS
- **Version Control:** Git, Github

# Why I built this

I wanted to gain more experience using API's. Github offers excellent documentation for their API's so I decided to create a Github search web app.
